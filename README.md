# 🏠 Ames Housing Price Prediction – Machine Learning

### 1. Project Title

🏠 Ames Housing Price Prediction – Machine Learning

A machine learning project developed using Python to analyze housing characteristics, explore property price patterns, and predict house sale prices using regression models.

---

### 2. Short Description

The Ames Housing Price Prediction project focuses on analyzing housing data and building machine learning models to estimate property sale prices based on residential features.

The project involves data preprocessing, exploratory data analysis, feature engineering, regression modeling, and model evaluation. Linear Regression and Random Forest Regression are used to compare predictive performance, while K-Means Clustering and DBSCAN are applied to explore patterns and groupings in the housing data.

### 4. Data Source

The project uses the Ames Housing dataset, which contains residential property information, including:

* Sale prices
* Overall quality and condition
* Living area and house size
* Construction and remodeling years
* Bathroom-related features
* Property characteristics
* Other housing attributes

The dataset is used to investigate relationships between property features and sale prices.

### Business Problem

House prices depend on multiple factors, including property size, quality, age, and other characteristics. Estimating prices consistently can be challenging without analyzing historical housing data and applying suitable predictive models.

### Goal of the Project

The goal of this project is to analyze residential property data, identify factors associated with sale prices, build regression models to predict house prices, and explore housing patterns through clustering techniques.

### Key Analysis Areas

* Sale Price Distribution
* Housing Feature Analysis
* House Age and Remodeling Analysis
* Total Living Area and Bathroom Analysis
* Relationships Between Housing Features and Sale Prices
* Linear Regression Model
* Random Forest Regression Model
* K-Means Clustering
* DBSCAN Clustering
* Model Performance Comparison using R² Score

### Model Performance

The regression models achieved the following R² scores in the project:

| Model                    | R² Score |
| ------------------------ | -------: |
| Linear Regression        |   0.8944 |
| Random Forest Regression |   0.9132 |

The Random Forest model achieved a higher R² score than Linear Regression in this experiment.

*Note: These results reflect the evaluation performed in the project. Performance may vary depending on preprocessing, feature selection, and train-test split.*

### Business Impact & Insights

The project helps to:
